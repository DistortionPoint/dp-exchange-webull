# Webull — every endpoint reference page the vendor publishes
#
# Captured 2026-09-09 from developer.webull.com/apis/sitemap.xml, filtered to
# `docs/reference/*`. One page per endpoint, which makes this set the venue's own index of
# what it serves — and therefore diffable. `script/check_endpoint_inventory.sh` compares it
# weekly.
#
# This is the venue's WHOLE published surface, not this package's. `endpoint-inventory.md`
# is the curated view (which surfaces exist, how many, and how much of each this package
# implements); this is the raw list a machine can compare. A page appearing here may mean a
# `capabilities/0` `:unsupported` declaration is now false; one vanishing may mean a claim
# this package makes has gone stale.
#
# Why this venue gets a captured list rather than a spec diff: Webull publishes no
# machine-readable specification. `dp_exchange_gemini` does, and its checker diffs the
# OpenAPI/AsyncAPI documents directly. This is the same mechanism against the only index
# this vendor offers.
#
# The mechanism has already paid for itself here: the identical sitemap search found
# `docs/rate-limits`, a per-endpoint rate-limit table that had existed since 2026-08-14
# while this package declared a REST ceiling five times too permissive — on a venue whose
# documented penalty for exceeding it is a temporary IP block.
